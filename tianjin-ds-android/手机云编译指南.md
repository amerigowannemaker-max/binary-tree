# 手机查看云端构建

工程已提交到 [GitHub 独立分支](https://github.com/amerigowannemaker-max/binary-tree/tree/codex/tianjin-ds-android-arm64-20261114)，原 main 分支不变。

1. 打开仓库的 Actions，选择 Tianjin DS Android ARM64 and SQLite verification。
2. 打开本分支的最近一次成功运行。
3. 下载 Artifacts 中的 tianjin-ds-2027-android-arm64-apk，解压后安装 .apk。
4. 编译日志、签名及测试结果在 tianjin-ds-verification-aarch64 和 tianjin-ds-verification-x86_64。

APK 是 ARM64 已签名调试版，应用标识为 com.study.dsbasics2027。手机无需安装 Rust、SDK 或 NDK。不要通过卸载应用来处理普通更新，否则应用沙箱内的本地答题记录会随卸载清除。

如需在其他仓库复用，把工程目录保留为 tianjin-ds-android，并把本工程内 .github/workflows/tianjin-ds-android.yml 放到新仓库根目录的同名路径，再调整工作流触发分支。
